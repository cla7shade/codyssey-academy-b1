## awk 문법과 옵션

`awk`는 명령어 출력에서 필요한 줄이나 값을 골라내고, 간단한 계산까지 수행하는 텍스트 처리 도구이다.

|                문법/옵션 | 의미                                            |
| -------------------: | --------------------------------------------- |
|          `awk '...'` | 입력을 줄 단위로 읽고, 따옴표 안의 awk 코드를 실행한다.            |
|            `-v 변수=값` | Bash의 값을 awk 내부 변수로 전달한다.                     |
|      `BEGIN { ... }` | 입력을 읽기 전에 한 번 실행한다. 입력 없이 계산만 할 때 사용한다.       |
|       `/패턴/ { ... }` | 패턴과 일치하는 줄에서만 `{ ... }`를 실행한다.                |
|                  `^` | 줄의 시작을 의미한다. `/^Mem:/`은 `Mem:`으로 시작하는 줄을 뜻한다. |
|     `$1`, `$2`, `$3` | 현재 줄을 공백 기준으로 나눈 필드 번호이다.                     |
|                 `NR` | 현재 줄 번호이다. `NR==2`는 두 번째 줄을 뜻한다.              |
| `gsub("A", "B", 대상)` | 대상 안의 `A`를 모두 `B`로 바꾼다.                       |
|             `printf` | 값을 지정한 형식으로 출력한다.                             |
|               `%.1f` | 실수를 소수점 한 자리까지 출력한다.                          |
|                 `%d` | 정수를 출력한다.                                     |
|                 `%%` | `%` 문자 자체를 출력한다.                              |
|                 `\n` | 줄바꿈을 출력한다.                                    |

## 스크립트에서 사용한 awk

|                                                      사용 구문 | 의미                                            |
| ---------------------------------------------------------: | --------------------------------------------- |
|          `awk -v total1=... -v total2=... 'BEGIN { ... }'` | Bash에서 넘긴 CPU 누적값으로 CPU 사용률을 계산한다.            |
|         `awk '/^Mem:/ { printf "%.1f", ($3 / $2) * 100 }'` | `Mem:` 줄에서 전체 메모리와 사용 메모리를 이용해 메모리 사용률을 계산한다. |
|              `awk 'NR==2 { gsub("%", "", $5); print $5 }'` | 두 번째 줄의 다섯 번째 값에서 `%`를 제거하고 출력한다.             |
| `awk -v v=... -v limit=... 'BEGIN { if (v > limit) ... }'` | 사용률이 임계값을 넘었는지 비교한다.                          |
